# Инструкция пользователя: Photo Sorter Pro 📸

**Photo Sorter Pro** — это компактный и мощный инструмент для тех, кто работает с большими архивами фотографий. Программа создана для максимально быстрого отбора кадров, их сортировки по папкам и очистки от брака.

---

## 🚀 Начало работы

1. Запустите файл `PhotoSorterPro.exe`.
2. **Настройка (при первом запуске):**
   * **ИСТОЧНИК:** Укажите папку, где лежат ваши новые фотографии.
   * **Папки 1–6:** Укажите папки, куда вы планируете распределять удачные снимки (например: *«Для ретуши»*, *«Семейные»*, *«В печать»*).
3. Нажмите кнопку **«СОХРАНИТЬ И ЗАПУСТИТЬ»**.

---

## ⌨️ Горячие клавиши (Управление)

*Работа в программе построена на использовании клавиатуры, что ускоряет процесс отбора в несколько раз.*


| Клавиша | Действие |
| :--- | :--- |
| **Стрелки ← / →** | Листать фотографии |
| **Цифры 1 — 6** | Переместить фото в папку №1, №2 и т.д. |
| **Клавиша R** | Повернуть текущее фото (или всю выделенную пачку) |
| **Клавиша Delete** | Переместить фото в папку `_DELETED` (корзина внутри источника) |
| **Ctrl + Z** | Отмена последнего действия (вернуть файл назад) |
| **Shift + Клик** | Выделить диапазон фотографий в ленте |
| **Ctrl + Клик** | Выборочное выделение нескольких снимков |
| **Escape** | Снять все выделения |

---

## 🛠 Ключевые возможности

### 📦 Массовая работа с файлами
Вы можете выделить группу фотографий в нижней ленте (через `Shift` или `Ctrl`). После этого любое действие (нажатие цифры, удаление или поворот) применится **ко всем выделенным снимкам одновременно**.

### 🔄 Система «Undo»
Если вы случайно нажали не ту цифру и файл «улетел» не в ту папку, просто нажмите `Ctrl + Z`. Программа мгновенно вернет его на место.

### ⚙️ Смена настроек
Если вам нужно изменить пути к папкам или выбрать другой источник, нажмите на иконку шестеренки **(⚙)** в нижней панели управления.

### 🖼 Адаптивный интерфейс
Программа автоматически масштабирует фотографии под размер вашего экрана. Просто разверните окно на весь экран для детального просмотра кадров.

---

## 📁 Техническая информация
* **Настройки:** Все пути сохраняются в файле `photo_sorter_settings.json` рядом с программой. Если вы хотите сбросить настройки, просто удалите этот файл.
* **Безопасность:** Программа никогда не удаляет файлы безвозвратно. Папка `_DELETED` создается внутри вашего источника, и вы всегда можете восстановить оттуда файлы вручную.
