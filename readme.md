# Photo Sorter Pro 📸

Профессиональный инструмент для быстрой сортировки и отбора большого количества фотографий. Позволяет мгновенно распределять снимки по папкам и удалять брак с помощью горячих клавиш.

## 🚀 Как запустить (Для пользователей)

Если вы хотите просто пользоваться программой:
1. Перейдите в папку `dist/`.
2. Запустите файл `PhotoSorterPro.exe`.
3. При первом запуске укажите папку-источник и до 6 папок назначения.

> **Примечание:** Файл `photo_sorter_settings.json` хранит ваши пути. Если нужно сбросить настройки, просто удалите этот файл.

## ⌨️ Горячие клавиши

*   **Стрелки Влево / Вправо** — навигация по фотографиям.
*   **Цифры 1–6** — перемещение выбранных фото в соответствующую папку.
*   **Delete** — перемещение фото в папку `_DELETED` (корзина).
*   **R** — поворот текущего (или пачки) фото на 90 градусов.
*   **Ctrl + Z** — отмена последнего действия (Undo).
*   **Shift + Клик** — выделение диапазона фотографий.
*   **Ctrl + Клик** — выборочное выделение нескольких фото.
*   **Escape** — снять выделение.

## 🛠 Структура проекта (Для разработчиков)

Проект написан на Python 3.12 с использованием библиотеки Tkinter и разбит на модули:

*   **`app_entrypoint.py`** — Точка входа. Управляет инициализацией и жизненным циклом приложения.
*   **`app_ui.py`** — Графический интерфейс. Отвечает за окна, кнопки, рендеринг фото и обработку кликов.
*   **`core_engine.py`** — Логическое ядро. Работа с файловой системой, кэширование миниатюр и история операций.
*   **`data_config.py`** — Модуль конфигурации. Сохранение и загрузка настроек в JSON.
