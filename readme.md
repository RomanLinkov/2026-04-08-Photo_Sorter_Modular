# Photo Sorter Pro v2.0 (Modular)

Модульное Python-приложение на базе Tkinter и Pillow для высокопроизводительной сортировки больших фотоархивов.

## 🏗 Архитектура проекта
Проект разделен на логические модули для удобства поддержки:
- `app_entrypoint.py`: Точка входа, управление жизненным циклом окна и путями (включая поддержку `sys._MEIPASS` для EXE).
- `app_ui.py`: Основной слой интерфейса, обработка горячих клавиш и стек истории (Undo).
- `core_engine.py`: Многопоточный движок. Использует `ThreadPoolExecutor` для фоновой генерации превью и "ленивой" записи поворотов на диск.
- `app_filmstrip.py`: Оптимизированный виджет ленты (Filmstrip) с пулом переиспользуемых Label-виджетов.
- `data_config.py`: Централизованное хранение констант, путей и логика работы с JSON-настройками.

## 🛠 Технологический стек
- **Python 3.10+**
- **Pillow**: Обработка изображений (используется метод `draft()` для ускорения декодирования JPEG).
- **Threading**: Фоновое выполнение I/O операций.
- **Tkinter**: Нативный GUI.
