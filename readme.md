**Photo Sorter Pro** — это высокопроизводительное десктопное приложение для профессиональной сортировки и базовой обработки фотоархивов. Главный приоритет программы — **скорость взаимодействия**.

---

## 💎 Ключевые особенности версии 2.2

*   🚀 **Full Background Precache**: При открытии директории приложение автоматически запускает фоновую генерацию миниатюр для всей папки.
*   📊 **Load Monitoring**: Визуальный индикатор в реальном времени показывает нагрузку на движок (`LOAD: N`).
*   ⚡ **Adaptive Navigation**: Внедрена логика "умной задержки" (70-100мс) при быстрой прокрутке. Интерфейс остается отзывчивым, даже если зажата клавиша навигации.
*   🧠 **Smart Cache Manager**: 
    *   **LRU-логика**: Автоматическое удаление кэша, к которому не обращались более 7 дней.
    *   **Size Limit**: Жесткий ограничитель на 500 МБ для предотвращения разрастания служебных данных.
*   ↩️ **Advanced Undo**: Стек истории позволяет отменять перемещения и удаления (файлы восстанавливаются из локальной корзины `.photo_trash`).
*   📂 **Dynamic UI**: Кнопки сортировки адаптивны — они подстраиваются под имена папок пользователя и скрываются, если пути не настроены.

## 🏗 Архитектура проекта

Проект построен по модульному принципу:

1.  **`app_entrypoint.py`**: Точка входа. Управляет инициализацией `Tkinter`, проверкой системных путей и предварительной очисткой кэша.
2.  **`app_ui.py`**: Уровень представления. Содержит логику горячих клавиш, систему Undo, верхнюю инфо-панель и адаптивную навигацию.
3.  **`core_engine.py`**: "Мотор" приложения. Использует `ThreadPoolExecutor` для параллельной обработки I/O и `Image.draft()` для ускоренного декодирования JPEG.
4.  **`app_filmstrip.py`**: Высокооптимизированный виджет ленты миниатюр с пулом переиспользуемых Label-компонентов.
5.  **`data_config.py`**: Хранилище констант, работа с JSON-настройками и алгоритмы умной очистки диска.
