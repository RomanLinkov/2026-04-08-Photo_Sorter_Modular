# Логика работы Photo Sorter Pro

1. **Инициализация**: Загрузка конфига -> Сканирование папки -> Создание кэша превью.
2. **Навигация**: 
   - Изменение `current_file` -> Обновление главного Label.
   - Сдвиг видимого окна в `Filmstrip`.
3. **Выделение**: 
   - Click: Clear + Add.
   - Shift+Click: Range Add (от последнего клика).
   - Ctrl+Click: Toggle.
4. **Действия**: 
   - Move/Delete: Удаление из `files_list` -> Обновление индексов -> Триггер `Filmstrip.refresh()`.
   - Rotate: Физическая перезапись -> Очистка кэша для этого файла -> Перерисовка.
